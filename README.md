# Time to Reorganise

*Work in progress for the SkillCorner x PySport Analytics Cup 2.0 (Defensive Positioning).*

A team-referenced, time-resolved metric of how quickly a football team returns to its own
organised defensive block after losing the ball.

Tracking data: [SkillCorner open data](https://github.com/SkillCorner/opendata) (A-League 2024/25).
Data is not included in this repository; fetch it with `scripts/download_data.sh`.

See `STATUS.md` for current progress.
